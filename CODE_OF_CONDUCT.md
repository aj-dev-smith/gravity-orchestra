# Code of conduct

Gravity Orchestra follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, critique the machine and not the person, and no
harassment of anyone, in any form.

It applies in issues, pull requests, discussions and anywhere else you represent the project.

## Reporting

Use GitHub's **Report content** option on the comment, issue or PR (the `...` menu), or
**Block user** if someone is bothering you. If you need the maintainer to step in, mention
@aj-dev-smith in a short, neutral issue or discussion asking to get in touch, without the details;
we'll take it somewhere private from there.

The maintainer may edit or remove comments, lock threads, and block people who break this code.
